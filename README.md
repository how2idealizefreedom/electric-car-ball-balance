# 2026 全国大学生电子设计竞赛 H 题 · 车载平衡滚球运动控制系统

基于 **TI MSPM0G3507** 的竞赛项目：小车沿黑线循迹并计时返回起点，同时通过倾斜摆杆使钢球在平台上保持稳定或完成指定位移。

## 系统组成

```
┌────────────┐   UART    ┌──────────────┐  STEP/DIR  ┌─────────────┐
│  K230 视觉  │ ────────▶ │  MSPM0G3507  │ ─────────▶ │  A4988 + 42 │
│ (GC2093)   │  球位置/速度 │   主控/状态机  │            │  步进摆杆   │
└────────────┘            └──────┬───────┘            └─────────────┘
                                 │ PWM/IN/STBY
                        ┌────────▼─────────┐
                        │  D24A (TB6612×2) │ ──▶ 四轮差速底盘
                        └──────────────────┘
                        八路灰度循迹 · 四按键 · OLED · CH340 遥测
```

## 硬件平台

| 模块 | 型号 |
| --- | --- |
| 主控 | TI MSPM0G3507（天猛星 LQFP-64 / 地猛星 LQFP-48） |
| 电机驱动 | WHEELTEC D24A（板载 2× TB6612FNG） |
| 行走电机 | MG310 直流减速电机 + 霍尔编码器（13 PPR，1:20） |
| 循迹 | 8 路红外数字灰度板 |
| 摆杆执行 | 42BYGH23-A-21DH 两相四线步进 + A4988 恒流驱动 |
| 视觉 | 立创庐山派 K230-CanMV + GC2093 |
| 姿态 | MPU6050 |
| 显示 | 0.96 寸 OLED（I2C） |
| 调试 | CCS 20.5 + XDS110 + 板载 CH340（115200） |

## 固件说明

所有工程均为 TI MSPM0 SDK + SysConfig 的 CCS 工程，`empty.syscfg` 是唯一有效的引脚 / 外设配置源，**不要手改 SysConfig 生成的文件**。

主工程 `firmware/H2_天猛星_路线记忆与步进/`：

- 八路灰度加权误差 → 差速 PD 循迹；
- 首圈人工示教（K2/K3）+ RAM 路线记录，回放以记忆为主、P1 小纠偏；
- A4988 步进点动 / 加减速 / 软件限位 / HOME，默认上电强制禁能；
- 5 ms 控制节拍（TIMA0）+ 100 µs 步进节拍（TIMG8）；
- 100 ms 串口遥测 `T,S,M,E,L,R`。

## 如何编译 / 运行

1. 安装 [Code Composer Studio](https://www.ti.com/tool/CCSTUDIO) 20.5 及以上版本与 MSPM0 SDK `2.11.00.07`。
2. `File → Import → CCS Projects`，选择 `firmware/` 下对应工程目录。
3. 按工程内的 `P0_TEST_GUIDE.md` → `P2_FINAL_LAP_TEST.md`（地猛星基线）或 `MEMORY_STEPPER_TEST.md`（天猛星步进）依次完成接线与分阶段测试。

**上电安全顺序**：先 MCU 单独上电并确认 STBY / ENABLE 安全电平 → 再接 A4988 → 最后接 D24A 并架空四轮。
