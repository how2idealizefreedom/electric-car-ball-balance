# 分阶段测试计划

## 0. 先解决供电开关

当前整机曾突然完全断电，用户判断大概率为板上供电开关问题。在它修好或可靠旁路前，不烧录、不接地跑车。

断开电机与步进执行机构后，分别验证：

1. MCU USB 供电保持 2 分钟，PB22 心跳和 CH340 串口不断线。
2. 电池→D24A Vin 保持 2 分钟；记录电池端、D24A Vin、D24A 5 V/3.3 V。
3. 灰度模块供电保持 2 分钟；串口 `M` 不应无规律跳成 255。
4. 轻触/晃动电源开关与插头，电压不得瞬断。

## 1. 只验证模式状态机，不给 D24A/步进电机功率

条件：车轮架空，D24A Vin 断开，A4988 VMOT 断开，只有 MCU USB/CH340。

预期启动信息：

```text
H1-H5 TIANMENG SAFE INTEGRATION - SDK 2.11.00.07
BASELINE=P1_22_44; MEMORY_REPLAY=OFF; A4988_IRQ=ON_DEMAND
MODE,Q=1,NAME=Q1_VIDEO,OLED=1
```

逐次短按扩展板 KEY2/PB11（逻辑 K4），应依次出现 Q2、Q3、Q4、Q5、Q1。PB22 在 WAIT 慢闪。空闲遥测中 `STIRQ=0`，证明 10 kHz 步进中断没有常开。

在 Q3 按 K1，当前应出现：

```text
STATE,BLOCKED,Q=3,REASON=K230_PROTOCOL_TBD
```

此时 PA25/A4988 ENABLE 应保持禁用，所有电机不应动作。

## 2. 只验证八路灰度

仍不接 D24A Vin。观察串口：

- 全白：`M=0`
- 仅中央 S4/S5 压黑线：`M=24`
- 从左向右扫黑线：对应位按 S1→S8 顺序变化

若全白仍是 `M=255`，先查灰度模块供电、地线和排线方向，不修改极性宏。

## 3. Q2 架空轮测试

条件：电源稳定，车轮架空，A4988 VMOT 仍断开。先切到 Q2，再接通 D24A Vin。

1. 按 K1 后应出现 `STATE,RUN,Q=2`。
2. 中央黑线时四轮都应向车辆前进方向转。
3. 手动把黑线移到阵列左右侧，左右轮差速方向应把车头拉回黑线。
4. 按 K1 应出现 `STATE,FAULT,...REASON=BUTTON_STOP`，PB15/STBY 变低。
5. 整个过程 `STIRQ=0`。

本车实测为前轮B/C向前、后轮A/D反向。保持代码方向极性不变，断电后交换后轮A的AIN1/AIN2控制线、交换后轮D的DIN1/DIN2控制线；B/C不动。修正后重新架空验证四轮同向。任一轮反向时只记录轮位、转向和串口，不翻转全局PD符号。

## 4. Q2 慢速完整一圈

第一圈使用当前冻结参数，不先改 PWM：

- 直线 220
- 中弯 190
- 大弯 160
- 搜线内/外轮 55/150
- Kp 0.7，Kd 1.8
- 丢线 400 ms 停车

必须收集：完整视频、内弯近景、`EVENT,LAP_ARMED`、返回 A 点前后约 1 秒串口、`STATE,BRAKE`、`STATE,FINISHED`、总时间、带正负方向的停车误差、电池电压。

若增重后只在弯道卡顿，先依据日志区分“仍看见线但内轮克服不了静摩擦”与“已丢线”。下一轮只允许修改一组弯道 PWM；不同时改 Kp、Kd、搜索速度和方向。

## 5. 屏幕

先断开 D24A Vin 和 A4988 VMOT，只给 MCU/扩展板 USB 供电。OLED 按模块正面朝向观察时标注顺序连接：GND→GND、VCC→3.3 V、SCL→PA31、SDA→PA28。禁止接反，首次上电前用万用表确认 VCC-GND 为约 3.3 V。

1. 上电后屏幕应出现 `MODE Q1`、题名、`WAIT` 和 `TIME 000.0S`。
2. 短按扩展板 KEY2/PB11，屏幕题号应按 Q1→Q2→Q3→Q4→Q5→Q1 变化，串口同步输出 `MODE,Q=...`。
3. 若屏幕不亮，记录启动串口是否出现 `WARN,OLED_NOT_DETECTED,UART_MODE_DISPLAY_ACTIVE`；测量空闲时 SCL/SDA 是否约 3.3 V。不要先改循迹参数或交换 SCL/SDA 猜试。
4. 屏幕与模式键通过后，再进行 Q2 架空轮测试。

## 6. A4988/42 步进轴

先完成相线、VMOT 去耦、电流限值、RESET/SLEEP、细分和 HOME 开关确认。A4988 使用 PA23/STEP、PA24/DIR、PA25/ENABLE、PB3/HOME。机构清空、D24A 禁用，只在 Q3 WAIT 状态用 K2/K3 每次 20 微步点动。

预期遥测：点动期间 `STIRQ=1`，到位后恢复 `STIRQ=0`。确认方向、回零、有效行程、水平零点和“微步/摆杆角度”后，才允许设置 `BALL_AXIS_CALIBRATED=1`。

## 7. K230 与 Q3—Q5

### 7.1 只验证K230串口，不接步进电机

1. D24A Vin和A4988 VMOT继续断开；K230保持自己的独立电源。
2. 万用表确认K230 GPIO3/UART1_TX空闲电压约3.3 V，不得为5 V。
3. K230 GPIO3/UART1_TX→扩展板 UART1 四针座的 PB7/RX；K230 GND→该串口座 GND。PB6/TX 和 +5V 均不接，禁止连接两块板的5 V输出。
4. 烧录后运行用户提供的 `find and send.py`。CH340遥测应出现 `K230=1`，以及随球运动变化的 `BV/BX/BE/BVX/BL/BSEQ`。
5. 球位于图像中心附近时 `BE` 应接近0；球向图像右侧移动时，按现有K230定义 `BE` 应增大。移出画面超过15帧后 `BV` 应变0。
6. 停止K230程序或断开TX后约200 ms，遥测 `K230` 应恢复0。

这一步通过前不连接A4988。当前帧中的 `x/err_x` 为像素、`vx` 为像素/帧；必须完成像素—毫米和帧周期标定后，才能调用 `ball_feedback_update()`并启用球控外环。

### 7.2 后续顺序

先独立验证位置、速度、丢失标志和超时，再标定步进轴，随后依次Q3→Q4→Q5，禁止并行调试。

Q4 在编码器/B 点实际判据完成前保持 `TRACK_B_DETECTOR_READY=0`，不得用固定时间冒充 B 点识别。

## 8. PB3 HOME两阶段测试

### 8.1 H0：只测开关，不允许步进运动

1. 车轮架空，断开D24A Vin和A4988 VMOT，只给MSPM0供电。
2. 限位开关使用COM和NO两端：COM接GND，NO接PB3；不得给开关接5 V或3.3 V。
3. 安装位置为摆杆最低端，在机械硬限位前约1～2 mm触发，避免电机顶死机构。
4. 保持`A4988_AUTO_HOME_READY=0`并烧录。遥测未按开关应为`HOME=0,HST=0`；手按开关应为`HOME=1,HST=0`。
5. 连续按压20次，确认无跳变、无MCU重启、PB11模式不切换。该步骤通过前禁止给A4988接VMOT。

### 8.2 H1：低速自动回零

只有H0、电源冷启动和A4988限流三项通过后，才允许把`A4988_AUTO_HOME_READY`改为1。上电后预期顺序：

```text
A4988,HOME_SEEK,TARGET=-400
A4988,HOME_FOUND,MOVE_LEVEL=320
A4988,HOME_READY,LEVEL=320
```

回零期间`HST=1`，回到水平点期间`HST=2`，完成后`HST=3`；超时或未找到开关为`HST=4`并禁用A4988。首次测试必须手持急停电源，若机构向远离HOME方向运动应立即断电，不得等待软件超时。

## 9. 电池供电冷启动排查

扩展板原理图中U19把12 V降为+5 V，输出仅标注C1=100 uF；该+5 V直接进入主控5 V母线，未见与主控USB 5 V之间的隔离。USB插入后系统恢复说明电池5 V支路可能存在开关接触、电压跌落、降压启动或母线预充问题，不能把USB当作启动按钮。

1. USB断开时测扩展板+5 V：上电前、刚合开关、故障时、恢复后各记录一次。
2. 临时用USB调试时断开扩展板到主控的+5 V连接，只保留共地；独立运行时再断开USB，使用确认稳定的5 V降压给主控。
3. A4988和D24A接12 V动力支路，OpenMV接独立5 V降压；所有地线最终汇到电池负极，避免步进电流经过MCU地线。
4. A4988 VMOT附近加220～470 uF/25 V电解电容；禁止带电插拔步进电机。
