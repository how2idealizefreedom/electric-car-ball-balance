# 天猛星扩展板接线与验证

依据：天猛星开发板引脚图/原理图，以及用户指定可信的 `SCH_Schematic1_2026-06-13.pdf`。

## 1. 必须先处理红色小板

照片中的红色模块是扩展板自带的双路 TB6612 接口，不是 74HCT 电平转换器。你的四个 MG310 继续由外接 D24A 驱动。建议断电后拔下红色模块，避免两块电机驱动并行工作；空出的右侧 8 针座可作为控制信号取点。

右侧 8 针座按原理图自上而下为：PA12/PWMA、PB19/AIN2、PB17/AIN1、固定 +5V/STBY、PA16/BIN1、PB24/BIN2、PA13/PWMB、GND。固定 +5V/STBY 那一针不要接外部 D24A 的 STBY。

## 2. D24A 控制线

| 功能 | 天猛星信号 | 接 D24A |
|---|---|---|
| 右侧 A+B PWM | PA12 | PWMA 与 PWMB |
| 右侧方向 1 | PB17 | 前轮 B：BIN1；后轮 A：AIN2 |
| 右侧方向 2 | PB19 | 前轮 B：BIN2；后轮 A：AIN1 |
| 左侧 C+D PWM | PA13 | PWMC 与 PWMD |
| 左侧方向 1 | PA16 | 前轮 C：CIN1；后轮 D：DIN2 |
| 左侧方向 2 | PB24 | 前轮 C：CIN2；后轮 D：DIN1 |
| 全局使能 | PB15（H56） | STBY |
| 信号地 | GND | D24A GND |

Motor A=右后、B=右前、C=左前、D=左后。后置A/D因机械安装朝向与前轮相反，方向输入必须按上表交叉；不能把同一侧前后轮的同名IN端直接并接。PB15 到 D24A STBY 建议加 10 kΩ 下拉。若沿用 74HCT 电平转换方案，以上七根控制线先进入 HCT 的 3.3 V 输入侧，再由 5 V 输出侧进入 D24A；所有地必须共地。

## 3. 八路灰度

灰度模块使用 3.3 V 供电，数字输出直接进入 MSPM0。车头朝前观察，传感器从左到右：

| 灰度 | GPIO | 扩展板位置 |
|---|---|---|
| S1 | PB5 | H56-10 |
| S2 | PB16 | H56-7 |
| S3 | PB12 | H56-5 |
| S4 | PB13 | H56-4 |
| S5 | PB23 | H56-3 |
| S6 | PB26 | H56-2 |
| S7 | PB27 | H56-1/最下端，按丝印 PB27 确认 |
| S8 | PB25 | H55-10 |

H56 的编号印刷方向容易看反，接线时只认 GPIO 丝印，不按“第几针”盲插。白底应归一化为 M=0；中央 S4/S5 压黑线应为 M=24。

## 4. MPU6050 与串口

扩展板 U41 已固定：VCC、GND、SCL=PA1、SDA=PA0、AD0=GND、INT=PB4。MPU6050 模块供电接 3.3 V 更稳妥；PA0/PA1 的 I2C 上拉应到 3.3 V。PA10/PA11 仍连接天猛星板载 CH340，115200 8N1。

初次循迹保持 `MPU6050_BOOT_PROBE=0`。只验证陀螺仪时再改为 1；上电串口应打印 WHO_AM_I=104（0x68）且 RESULT=0。

## 5. 分阶段测试

1. D24A 断电、红色模块拔下，烧录后确认 PB22 慢闪，串口出现 `H2_LINE_CAR_TIANMENG P1`。
2. 万用表确认 PB15 在复位/待机为 0 V。
3. 只接灰度，验证白底 M=0、中央黑线 M=24、左右移动时位图方向正确。
4. 架空四轮后给 D24A 上电，按 PB21；四轮必须都朝车头方向转。同一侧前轮正确、后轮反向时交换该后轮的IN1/IN2控制线；只有整侧同时反向时才考虑修改 `RIGHT_FORWARD_IN1_HIGH` 或 `LEFT_FORWARD_IN1_HIGH`。
5. 最后落地用当前稳定速度验证一圈；天猛星首测不提速。
