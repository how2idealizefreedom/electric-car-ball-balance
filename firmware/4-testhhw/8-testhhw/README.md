# 8-testhhw

立创·地猛星 MSPM0G3507 开发板的“四路模块 + 四个单路模块”八路红外数字输出测试工程。

## 接线

所有模块必须与开发板共地。优先使用 3.3V 给模块供电，以免把 5V 高电平送入 MSPM0 GPIO。

| 通道 | 地猛星端口 | 排针位置 |
| --- | --- | --- |
| CH1 | PB24 | H3-7 |
| CH2 | PB20 | H3-8 |
| CH3 | PB19 | H3-9 |
| CH4 | PB18 | H3-10 |
| CH5 | PA7 | H3-11 |
| CH6 | PB2 | H3-12 |
| CH7 | PB3 | H3-13 |
| CH8 | PA8 | H3-14 |

四路模块可接 CH1-CH4，四个单路模块依次接 CH5-CH8。全部模块的 VCC 接 H3-19/H5-19 的 3V3，GND 接 H3-20/H5-20 的 GND；电源线可以通过面包板分配。

如果模块只能使用 5V 供电，必须先确认每个数字输出高电平不超过 3.3V；否则需要电平转换，不能把 5V 输出直接接到上述 GPIO。

## CCS 导入与测试

1. 解压工程，在 CCS 中选择 `Import CCS Project(s)`，选中本目录或 `8-testhhw.projectspec`。
2. 工程不锁定调试器类型；首次下载时按你实际使用的 XDS110、J-Link 或 CMSIS-DAP 选择连接方式。
3. 编译、下载并运行。
4. 打开地猛星板载 CH340 对应的串口，设置为 `115200, 8N1, 无流控`。
5. 串口每 200 ms 输出一次 `CH1=... CH8=...`。
6. 依次遮挡、移开或在黑白表面之间移动每个传感器。对应 `CHn` 能在 `0` 和 `1` 之间翻转，就说明该通道可以工作。

如果某一路始终不变化，先检查 VCC、GND、OUT 接线；带电位器的模块再调节比较器阈值。
