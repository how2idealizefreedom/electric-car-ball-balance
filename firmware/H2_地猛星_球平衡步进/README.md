# H2_LINE_CAR

立创·地猛星 MSPM0G3507（LQFP-48）+ CCS 的题目第二问工作工程。P0 已由实板验证，当前进入 **P1 低速循迹联调**：

- 基于 `11_PID_car` 的 CCS 工程元数据重新整理；
- 目标 SDK：MSPM0 SDK `2.11.00.07`；
- SysConfig：`1.26.2`；
- XDS110 目标配置保留；
- PA10/PA11 提供 115200-8-N-1 调试串口；
- PA14 为状态 LED（高电平点亮）；
- PB24（地猛星 H3-7）为 D24A 全局 STBY，复位、待机和故障时强制为低；
- PA12/PA13 输出左右两组 20 kHz PWM，四电机按右侧 A+B、左侧 C+D 分组；
- 八路数字灰度物理输出为白底低、黑线高，直接按 `1=黑线` 运行 5 ms 加权 PD；
- PA24 外接按钮用于启动和运行中急停；
- 离开起点横线且运行超过 6 s 后，才允许识别回到 A 点并短刹停车；
- 未复制旧工程的 `Debug/`、历史 `.out` 和旧 PID/电机代码。

## 当前安全边界

D24A 原理图将 TB6612 的 `VCC` 接到板载 5 V。TB6612 手册规定输入高阈值最小值为 `0.7 * VCC`，因此 MSPM0 的 3.3 V GPIO 不能作为有保证的高电平直接驱动 D24A。正式连接控制线前需要增加 3.3 V 到 5 V 的逻辑电平转换。

编码器插座向电机霍尔板提供 5 V；在编码器输出电平未实测/确认前，不得把 E1A/E1B...E4A/E4B 直接接入 MSPM0。
