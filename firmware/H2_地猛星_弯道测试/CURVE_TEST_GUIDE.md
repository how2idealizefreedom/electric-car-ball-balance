# 地猛星内弯恢复实验版

本工程从 2026-07-29 22:44 左右验证稳定的 `H2_LINE_CAR` 基线复制而来。原工程未修改。

## 只改变了什么

- 正常识线时的直线速度、PD 参数、方向极性和停车逻辑保持不变。
- 丢线后的搜索改为两段：
  - 0~180 ms：内侧 3%、外侧 18%，继续沿最后误差方向找线。
  - 180~1100 ms：内侧停转、外侧 26%，提高 24 cm 宽底盘的转弯能力。
- 连续丢线达到 1100 ms 后仍进入 `STATE,FAULT,LINE_LOST`，不会在全白场地无限转圈。
- 全白 `M=0` 时拒绝启动，输出 `EVENT,START_REJECT,NO_LINE`。
- 串口增加：
  - `EVENT,LINE_LOST_BEGIN,T=...,E=...`
  - `EVENT,LINE_REACQUIRED,T=...,D=...,M=...`
  - 周期遥测增加 `X=`，表示当前连续丢线时间（ms）。
