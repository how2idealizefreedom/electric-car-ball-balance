# 步进摆杆执行机构方案决策

> 决策对象：H 题"水平平台小球平衡"的摆杆执行机构选型。
> 结论版本：2026-07-31，与《开发记录与技术决策》中的执行机构路线更新保持一致。

## 一、选型结论

摆杆主执行器采用 **42BYGH23-A-21DH 两相四线步进电机 + A4988 恒流驱动**，替代早期的 MG996R 舵机方案。

选步进的理由：

1. **目标位置可离散控制**。第 3 问要求小球在中心 O 与 ±5 cm 之间运动并稳定，舵机只能接收角度命令，无法直接对应"球位移"这一被控量；步进可以用微步数直接表达摆杆倾角目标，位置指令与球位标定后是一一对应关系。
2. **重复性更好**。步进在不过载、不回零丢失的前提下没有累计误差，适合反复回到同一倾角做稳定实验。
3. **可与视觉闭环自然衔接**。K230 输出的钢球位置、速度经外环计算后得到摆杆目标倾角，再折算为步进微步位置，控制链是连续的。

需要明确的是：**A4988 是开环驱动器**，没有编码器反馈，丢步不可检测。因此它不能单独作为最终方案，必须配合下列约束：

- 上电后必须先回零（HOME），并需要机械限位与硬止挡；
- 必须有防撞与合理的电流限流（VREF 标定），避免失步与过热；
- 软件限位必须由实物行程标定得到，不能由理论尺寸推导。

## 二、为什么不用 MG513XP28_12V

资料照片中的 WHEELTEC `MG513XP28_12V` 是**直流减速电机**，不是步进电机，不能直接由 A4988 驱动。若采用它，需要另配 H 桥、增加编码器位置闭环和回零逻辑，复杂度高于当前的步进路线，因此不进入主路线。该电机后续是否用于行走机构的速度闭环，另见编码器相关条目。

## 三、控制路线

```
K230(球位置/速度/时间戳)
   │ UART
   ▼
MSPM0 ──超时检查 + 低通滤波──▶ 位置/速度
   │
   ▼
外环：angle_target = Kp * position + Kd * velocity
   │
   ▼
几何标定：倾角 ──▶ 步进微步位置（含位置/速度/加速度限幅）
   │
   ▼
10 kHz 定时器产生 STEP 脉冲；5 ms 控制环更新速度规划
```

分步说明：

1. K230 以 30~50 Hz 输出钢球相对摆杆中心的位置、速度和数据时间戳。
2. MSPM0 对数据做超时检查与低通滤波，超时视为掉线。
3. 外环按 `角度目标 = Kp*位置 + Kd*速度` 计算摆杆目标倾角。
4. 几何标定把倾角换算成步进微步位置，并做位置、速度、加速度三重限幅。
5. 10 kHz 定时器产生 STEP 脉冲，5 ms 控制环更新速度规划。
6. 上电后先低速向 HOME 运动，触发后回退并二次接近，建立零点。
7. 安全策略：K230 数据超时、HOME 异常或越过软件限位时，摆杆缓慢回中心，并禁止继续扩大倾角。

## 四、机械建议

- 微步先用 1/8 细分；曲柄有效半径从 12~18 mm 起试，以实际杆端位移标定结果为准。
- 转轴用轴承，连杆孔避免明显间隙；建议加轻量回中弹簧或配重，减轻步进保持负担（降低发热与失步风险）。
- HOME 放在机械安全端，另设硬机械止挡；**HOME 不能替代止挡**。
- 最终可用行程必须由实物尺寸计算加小步进试验标定。当前固件只开放 ±20 微步的点动测试范围，属于安全 bring-up 限制，不是最终行程。
