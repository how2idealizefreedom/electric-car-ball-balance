## 4. 引脚分配规则

- 最终引脚表只能在收到主控原理图/引脚图、各模块手册和现有 CCS 工程后确定，并以项目 `.syscfg` 和 MSPM0G3507 封装复用能力验证结果为准。
- `.syscfg` 是引脚、外设、时钟、中断和 DMA 的唯一配置源；禁止手改生成的 `ti_msp_dl_config.c/.h`、`Debug/`、`Release/`、对象文件、map 或 `.out`。
- 地猛星普通功能保留 PA2(ROSC)、PA3/PA4(LFXT)、PA5/PA6(HFXT)、PA18(BSL)、PA19/PA20(SWD)、PA21/PA23(VREF)、PA10/PA11(板载 CH340 UART) 和 PB14～PB17(板载 SPI Flash)。PA0/PA1 带板上可配置上拉网络，使用前核对焊桥状态。
- PA14 是地猛星板载用户 LED（高电平点亮）；PB24 已引出到 H3-7，当前安全基线用作 D24A STBY。NRST、SWDIO、SWCLK 及启动相关引脚必须保留。
- 优先资源顺序：调试 UART、左右电机 PWM/方向、左右代表编码器、灰度输入、启动/急停按键、显示屏；随后才是四轮独立编码器、MPU6050 和摆杆/摄像头扩展。
- 若四轮按左右两组并联驱动，至少读取每侧一个可靠编码器作为速度闭环；若需要四轮独立驱动，必须确认有两片双通道 TB6612 或等价四通道资源，再分配 4 PWM、8 方向控制和相应编码器引脚。
- 输出最终引脚表时必须包含：MCU 管脚、SysConfig 实例、模块端管脚、方向、逻辑电平、供电、电气注意事项和占用理由。用户确认接线后才能烧录对应驱动。

## 5. 固件总体架构

优先采用无 RTOS、定时器节拍驱动的分层结构；若用户提供的工程已有框架或 RTOS，则遵循现有目录和任务边界，不强行改造。

- `bsp/` 或现有板级层：GPIO、时钟、Timer、PWM、Capture/Encoder、UART、I2C/SPI、按键、显示。
- `drivers/` 或现有驱动层：TB6612、灰度模块、编码器、显示屏；MPU6050 暂留接口。
- `control/`：电机速度 PI、循迹 PD/PID、速度规划、停车控制、限幅和抗积分饱和。
- `app/`：状态机、圈次/停车线判定、计时、故障处理、遥测命令。
- 不因技能示例存在上述目录就擅自新建；先识别用户工程的既有结构，简单工程也可保持少量文件。

建议状态机：

1. `SAFE`：复位默认态，TB6612 禁能，PWM 为 0。
2. `IDLE`：显示待机，允许灰度/编码器校准和串口检查。
3. `ARMED`：确认传感器有效、起点条件成立，等待启动键。
4. `RUN`：启动计时，运行循迹与轮速闭环；初始屏蔽停车线识别。
5. `FINISH_BRAKE`：识别返回 A 点后按距离/速度曲线减速和制动。
6. `FINISHED`：电机禁能或安全制动，显示总时间并锁存结果。
7. `FAULT`：丢线超时、编码器异常、传感器无效或命令急停，立即输出安全态。

## 6. 第二问控制方案

### 6.1 循迹

- 先对灰度通道做白底/黑线标定、归一化和有效性检查，再用加权质心得到横向误差；不能仅用单阈值开关控制。
- 第一版采用循迹 PD，误差较大时自动降速，直道逐步提速；若存在稳态偏差再加小积分，并设置积分限幅。
- 丢线只允许短时间按最后误差方向受限搜索；超时进入 `FAULT`，禁止满速盲走。

### 6.2 轮速与里程

- 左右轮组分别做编码器速度 PI，外层循迹控制只给左右目标速度差。这样电池电压、负载和电机差异不会直接破坏轨迹。
- 记录左右里程、平均里程、速度和方向；编码器符号在架空车轮测试中统一。
- 推荐先用 1 ms 基础定时中断，只置标志或做极短采样；速度环和循迹环可先从 5～10 ms 周期起步。最终周期必须根据编码器分辨率和实测噪声调整。
- 电机 PWM 可从约 20 kHz 起步，但必须以模块手册、SysConfig 能力和实测为准。

### 6.3 回到 A 点与精准停车

- A 点有一条与环路垂直、长 5 cm 的黑色启停线。灰度阵列出现“多数/全部通道同时为黑”的横线特征时产生候选事件。
- 启动后必须设置初始屏蔽窗口，且只有完成足够运行时间、累计里程或赛道阶段后才允许把横线识别为回圈；避免在起点立即结束。
- 建议融合三类门限：横线空间特征、最小运行时间/里程、赛道阶段计数或航向变化。MPU6050 未安装时可先使用里程和循迹曲率阶段。
- 检测到返回 A 点后不要立刻断电滑行；实测制动距离，采用提前触发、斜坡减速和 TB6612 短刹车/禁能的组合，并以车身中心轴线上的指定测试位置对齐基准线。
- 串口持续记录候选线时刻、触发时刻、目标/实际速度、累计里程、制动阶段和最终时间，供停车点误差回归。

### 6.4 显示和按键

- 第二问最低需要 1 个独立启动键；建议安装 4 个键用于启动/确认、停止/急停、模式切换、参数增减，便于后续题目与现场调参。
- 按键必须软件消抖，长按停止键可作为紧急停机入口。
- 显示屏尺寸必须 `<= 2 英寸`；启动时开始计时，停车时锁存并显示总时间。调试阶段可轮播状态、传感器误差、左右速度和故障码。

### P1：工具链与安全基线

- 在电机断开或 TB6612 禁能时完成板载 LED、调试 UART、SysConfig、编译、XDS110 烧录和 System Reset 验证。
- 固件复位后必须保持电机关闭；任何调试暂停前先架空车轮或断开电机功率。
- 产出：明确的构建命令、`.out` 路径、匹配 XDS110 的 `.ccxml`、串口端口与波特率。

### P2：单模块驱动

- 按键：原始电平、消抖、短按/长按。
- 显示：显示固定文本，再显示毫秒计时。
- 灰度：逐通道输出原始值和归一化值，完成白/黑标定与横线识别。
- 电机：架空车轮，逐通道低占空比验证方向、PWM、STBY 和安全停机。
- 编码器：验证四轮或左右代表轮的计数、方向、每转计数和速度换算。
- 每个模块单独通过后才允许组合；一次只改动一个可验证变量。

### P3：底盘闭环

- 分别完成左右速度 PI，做阶跃、斜坡、低电压和负载测试。
- 做直行闭环和受控减速，标定最小启动 PWM、死区、左右差异、最大安全速度和制动距离。
- 产出：速度曲线、PI 参数、采样周期、轮径/轮距标定值和停止距离表。

### P4：低速循迹

- 先在局部直线和半圆测试灰度误差方向、PD 极性、丢线保护和速度调度。
- 再做不计时完整一圈，确认车身投影始终在线路上。
- 产出：循迹参数、各段误差峰值、丢线次数、圈时和串口日志。

### P5：A 点识别与停车

- 在低速下反复通过启停线，统计误检/漏检和触发位置。
- 增加初始屏蔽、最小里程/时间及阶段门控；调节提前量和制动曲线。
- 至少重复 10 次，记录相对基准线的有符号停车误差。先要求无误停且绝对误差稳定小于 2 cm，再提高速度。

### P6：20 秒指标优化

- 逐步提高直道基准速度，弯道按误差和曲率降速；每次只修改一组参数。
- 每轮保存固件版本、参数、总时间、停车误差、最大循迹误差、电池电压和异常。
- 交付门槛：连续多次满足 `<= 20 s` 与 `<= 2 cm`，并保留明显安全余量；不是单次偶然通过。

## 8. CCS / SysConfig / 编译烧录规则

- 修改前先定位 `.syscfg`、应用入口、生成的 `ti_msp_dl_config.h`、`targetConfigs/*.ccxml` 和当前构建输出。
