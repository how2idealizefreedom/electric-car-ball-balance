# 开发记录与技术决策

> 本文记录 2026 年全国大学生电子设计竞赛 H 题（车载平衡滚球运动控制系统）的方案决策、硬件结论、算法基线与验证状态。
> 全文严格区分四种状态：**已实车验证**、**已构建未实板**、**仅理论设计**、**未开始**。没有证据的内容不写成事实。
> 记录截止：2026-07-31（执行机构路线更新后）。

## 1. 题目与评分指标

**题目**：2026 年电赛 H 题"车载平衡滚球运动控制系统"。

第一优先级为第 2 问：小车置于 A 点，按键启动，沿黑线顺时针行驶一圈，回到 A 点自动停车、停止计时并显示总时间。

| 指标 | 要求 |
| --- | --- |
| 总时间 | ≤ 20 s |
| 停车偏差 | ≤ 2 cm |
| 黑线宽度 | 1.8 ± 0.2 cm |
| AB、CD 直线段 | 各 1.5 m |
| BC、DA | 半径 0.5 m 的半圆 |
| A 点启停线 | 长 5 cm |
| 车辆最大外形 | 35 cm × 25 cm |
| 显示屏 | 不大于 2 英寸 |

中心线路程估算约 6.14 m。

第 3~6 问要求：摆杆将小球在中心 O 与 ±5 cm 之间运动并稳定；经 B 点或行驶一整圈过程中，钢球稳定在中心或指定位置附近，误差绝对值 ≤ 1 cm；有关行驶项目的时间上限为 8 s 或 30 s（以题目原文为最终准则）。

## 7. 供电与电平安全

### 已实测

- 电池满电测得约 12.14 V。
- D24A `5V-GND`、`3V3-GND` 万用表测为正常（未保存精确数值）。
- 已完成"电脑供电、车轮架空"的电机试验，CH340 有串口数据。
- 灰度模块可按 3.3 V 供电，实测白底数字输出 0 V、黑线约 3.3 V。
- 系统必须共地：MCU GND 与 D24A GND 作为接线要求反复确认。

### 设计结论

- 调试拓扑：电脑 USB 给 MCU / CH340 供电，12 V 电池给 D24A `Vin+/-` 与电机功率；MCU 与 D24A 只做信号地共地。USB 给 MCU 时不得把 D24A 的 5 V / 3.3 V 输出并接 MCU 电源，避免倒灌。
- 脱机供电：天猛星的脱机电源入口为**待定项**，不能把旧地猛星的电源结论直接迁移。
- MG996R 不能从 MSPM0 3.3 V 或 MCU USB 细供电线取功率，需独立足够电流的 5~6 V 降压并与 MCU 共地。
- 42BYGH23 不能由 MCU GPIO 或普通降压模块直接驱动；当前经 A4988 恒流斩波驱动，逻辑 VDD = 3.3 V、VMOT = 12 V，VMOT 旁至少 100 µF 电容，所有地共地。
- 执行器上电顺序：先 MCU 单独上电并验证 PB15 / PA25 安全电平，再单独接 A4988，最后才接 D24A 并架空四轮。

### 未定案的冲突：TB6612 5 V 逻辑与 3.3 V MSPM0

- 旧地猛星供电文档依据其对 D24A 原理图 / 手册的解读，认为 TB6612 VCC = 5 V、保证 VIH = 0.7×VCC = 3.5 V，因此建议 74HCT / 74AHCT 缓冲，并禁止把可调 DC-DC 当成电平转换。
- 天猛星接线文档写为"TB6612FNG 控制高电平门限低于 3.3 V，MSPM0 可直接驱动，无需 HCT"。
- 两者相互矛盾，且没有"天猛星 3.3 V 直连 D24A 在噪声 / 温度下可靠"的实测记录。后续必须以 D24A 所用 TB6612FNG 的原始数据表版本、实际 VCC 以及示波器实测为准，不把任一文档结论当作已实板定案。

### 待确认：编码器电平

D24A 编码器插座可提供 5 V。若霍尔 A/B 为 5 V 推挽输出，不能直接进 MSPM0；若开漏且可上拉到 3.3 V 才可能安全。加上电机型号存在 MG310 与 MG513XP28_12V 的冲突，每轮计数、PPR 定义、编码器输出电平均仍是待定项。

## 8. 循迹算法（稳定基线）

"当前认可稳定"特指地猛星 2026-07-29 约 22:44 的 P1 基线，对应 `firmware/H2_地猛星_循迹主线/` 中的 `main.c` 与 `car_config.h`。它不是天猛星记忆工程的实车验证结论。

### 算法事实

- 传感器定义：`LINE_BLACK_IS_HIGH = 1`；`line_read()` 将 S1~S8 组合为位图，`1 = 黑线`。实测白底应为 `M = 0`，中央 S4/S5 压线为 `M = 24`。
- 权值：S1~S8 分别为 `−350, −250, −150, −50, 50, 150, 250, 350`。
- 误差：所有激活传感器权值的算术平均；没有激活传感器则认为丢线。
- PD：`turn = error*0.7 + (error − lastError)*1.8`，再限幅到 ±400。
- 基础 PWM（千分比，0~1000，最终上限 350）：绝对误差 ≤ 150 用 220；150 < |E| ≤ 250 用 190；|E| > 250 用 160。
- 差速：`left = base + turn`，`right = base − turn`；方向极性只依据实际架空 / 落地测试确定。
- 丢线：按最后误差方向执行 55/150 差速搜索，连续 400 ms 丢线后进入 `STATE,FAULT,LINE_LOST`。
- A 点识别：不是名为 `LAP_ARMED` 的状态，而是 `g_leftStartLine`——先见到非宽线后置真；运行至少 6000 ms 后，连续 4 个 5 ms 控制周期（约 20 ms）出现 ≥ 6 路黑线，即进入刹车。
- 刹车：`motor_short_brake()` 将四个方向输入置高、PWM 写 1000，维持 220 ms；随后 `motor_coast_disable()`，输出 `STATE,FINISHED`。
- 计时：`g_runMs` 在 5 ms 控制步进中累加；进入刹车时锁存 `g_finishMs`，完成时加 220 ms 后输出。
- 遥测：每 100 ms 输出 `T,S,M,E,L,R`（运行时间、状态、位图、上次误差、左右命令）。

### 稳定基线参数

| 参数 | 数值 | 证据等级 |
| --- | --- | --- |
| 控制周期 | 5 ms | 源码存在，地猛星实车曾用 |
| 遥测周期 | 100 ms | 同上 |
| 最短终点允许时间 | 6000 ms | 源码存在；停车精度未验证 |
| 宽线条件 | ≥ 6 路，连续 4 tick | 源码存在 |
| 短刹时长 | 220 ms | 源码存在 |
| 丢线故障 | 400 ms | 源码存在；对当前赛道内弯是否合适未完整验证 |
| 直 / 中 / 大弯 PWM | 220 / 190 / 160 | 实车反馈"慢但稳定" |
| 搜索内 / 外 PWM | 55 / 150 | 历史基线 |
| PD | Kp 0.7，Kd 1.8 | 用户认可基线 |
| PWM 上限 | 350 | 源码存在 |

天猛星记忆工程的参数与上述基线不同：丢线上限为 TEACH / REPLAY 各 1500 ms，且有示教 / 回放逻辑。因未实板，不能称稳定。

| PWM 下降 | 空载观感过快，直线 PWM 从约 35% 降为 22%、上限 35% | 反馈稳定，转弯慢但可稳定 |
| 22:44 稳定版 | P1 PD、220/190/160、55/150 搜索、400 ms 故障、6 s 宽线终点、220 ms 短刹 | **认可为地猛星稳定基线** |
| 高性能尝试 | 启动斜坡、内轮最低 PWM、强制找线、极性修改等 | 反馈直线突然加速、抽搐，内弯切线冲出 / 很快丢线，甚至全白地逆时针转圈后停；已撤销或隔离到实验副本 |
| 天猛星 P1 迁移 | 基于稳定 P1 新建 LQFP-64 天猛星外接 D24A 版，PB22 LED、PB15 STBY | 已构建，未实板 |
| 天猛星记忆 + A4988 | 首圈 P1 + 人工 K2/K3 示教，40 ms RAM 记录；回放以记忆为主、P1 小纠偏；步进点动 | 已构建，未烧录 |

## 10. 验证状态总览

### 已实车验证

- 地猛星 P0 安全固件四项完成。
- 板载 LED 为 PA14 的直接实测纠正。
- CH340 串口通道可用（有连续 `T/S/M` 数据）。
- 灰度黑白极性（白 0、黑 3.3 V；M=0 / M=24）。
- 四轮直行动作（重接线后可走直线；不证明当前天猛星接线 / 固件有效）。
- 地猛星稳定 P1："稳定，转弯比较慢但是可以稳定"；22:44 版本可执行但速度不满足最终目标。
- K230 Wi-Fi 图传跑通。

### 已构建未实板

- 天猛星记忆 + 步进工程：SysConfig 检查与生成、源码、startup、链接均通过。
- 天猛星 P1 迁移工程。
- A4988 的 STEP/DIR/ENABLE/HOME、100 µs 定时器、点动 / 加减速 / 限位代码已写入并完成构建，未接通 VMOT 实测。
- MPU6050 底层文件已加入，启动探测默认关闭，未做传感器实测。

### 已实现但效果不满足要求

- 地猛星后续高性能 / curve 类修改：直线突然加速、一卡一卡抽搐，内弯冲出、丢线、全白原地逆时针转圈。
- 稳定循迹能慢速 / 局部稳定，但尚无连续完整一圈 ≤ 20 s 且停车 ≤ 2 cm 的记录。
- A 点检测 / 短刹代码能输出 `STATE,BRAKE/FINISHED`，但没有停车偏差合格的实测证据。

### 仅理论设计

编码器速度 PI、里程标定、终点多条件识别、OLED 显示、MG996R 独立供电与机械标定、42 步进的正式 HOME 与行程换算、球控执行器闭环、K230 UART 协议与 MSPM0 接收、球位置外环 PID、图传与最终供电合并。

### 尚未开始

天猛星工程烧录与实板接线验证、完整一圈示教与回放实测、编码器接线与标定、OLED 驱动、K230 到 MSPM0 的 UART 联调、钢球闭环 PID、第 3~6 问验收。

## 11. 已放弃或被撤销的方案

| 方案 | 原因 | 结论 |
| --- | --- | --- |
| PWM 启动斜坡 | 第一段直线突然加速、匀速性差 | 撤销；重新引入前须做单变量台架与实车对比 |
| 内轮最低 PWM | 内弯转向不足，容易按切线冲出 | 撤销；稳定基线允许内轮按差速降低 |
| 0/28% 强制找线 | 全白情况下曾出现逆时针失控转圈 | 不作为稳定策略 |
| 凭日志 / 视频推断翻转转向符号 | 后续发现后轮动力线 / 线松等硬件因素 | 禁止；必须以架空四轮和低速落地直测为准 |
| 按时间划分直线 / 弯道 | 长按启动 / 只能转弯；不能适应起点偏差与电池变化 | 撤销；不能以时间表替代赛段识别 |
| 短按切模式、长按启动 | 实操反馈问题 | 撤销；改用短按消抖事件 |
| 地猛星 curve 路线 | 直线抽搐、第二弯冲出 | 不再作为开发对象 |
| MG996R 直接球控 | 只能接收角度命令，无视觉位置闭环无法保证球误差；供电 / 机械细节未齐 | 不作为当前执行主线 |

## 13. 工程约束（开发规范）

1. 不覆盖或静默改写 `firmware/H2_地猛星_循迹主线/` 的 22:44 稳定基线；新想法必须复制为独立工程。
2. 一次实车测试只修改一个控制变量；速度、PD、方向、丢线搜索、刹车不能一起改。
3. 不根据视频、串口符号或"看起来"翻转转向极性；必须以架空四轮和低速落地的直接实测为据。
4. 不以时间表替代实际赛段 / 线路识别。
5. 不手改 SysConfig 生成文件；只修改 `.syscfg` 后重新检查与生成。
6. 未确认共地、STBY、ENABLE、逻辑电平、执行机构安全状态前，不烧录或运行可能驱动执行器的固件。
7. 不把"SysConfig / 编译 / 链接成功"写成"烧录成功"或"实车成功"。
8. 不把旧地猛星的电源结论直接套到天猛星；不未经确认并联 USB、D24A 5 V、XDS110 供电。
9. 不把 5 V 编码器输出、K230 UART 电平或 OLED 接口当作已知；先测量 / 查实际资料。
10. 不在没有 HOME 和机构标定时接入钢球闭环。

## 14. 测试记录规范

每次循迹实测必须以一个固定固件版本加一组固定参数为单位，收集：

- 固件工程路径、`car_config.h` 参数、构建时间 / 输出文件名、是否重启过 MCU；
- 电池静置电压与测试后电压；
- 返回 A 点前后各约 1 秒的完整串口数据；
- `STATE,BRAKE,T=...` 与 `STATE,FINISHED,T=...`，或故障的完整 `STATE,FAULT,...`；
- 一圈总时间；
- 停车偏差：以固定车体测量标记为准，越过基准线为正、未到为负，单位 cm；
- 至少一个内弯的连续视频（能看见车体、灰度板、轨迹）；
- 最终停车视频；
- 起步位置、车头方向、是否有人按 K2/K3 人工辅助。

针对天猛星记忆工程，额外收集 `MODE=T/R`、`MEM=当前/总数`、`STEP=position/target`、`M/E/L/R`；首圈示教与回放必须分别保存完整日志。
