## 1. 项目背景与竞赛任务

- 题目：2026 年“车载平衡滚球运动控制系统”H 题。
- 当前第一优先级曾明确为第 2 问：小车置于 A 点，按键启动，沿黑线顺时针行驶一圈，回到 A 点自动停车、停止计时并显示总时间。硬指标为总时间 `<=20 s`、停车偏差 `<=2 cm`。
- 赛道参数来自根目录 `AGENTS.md` 对题目 PDF 的摘录：黑线宽 `1.8±0.2 cm`；AB、CD 直线各 `1.5 m`；BC、DA 为半径 `0.5 m` 的半圆；A 点启停线长 `5 cm`；车辆最大外形 `35 cm × 25 cm`；显示屏不得大于 `2 英寸`。中心线路程估算约 `6.14 m`。
- 后续第 3～6 问的用户截图要求包括：摆杆将小球在中心 O 与 `±5 cm` 间运动并稳定；经 B 点/一圈过程中钢球稳定在中心或指定位置附近，误差绝对值 `<=1 cm`，有关行驶项目时间上限为 `8 s` 或 `30 s`（以题目原文为最终准则）。
- 当前实际工作方向已从地猛星切换为：**天猛星 MSPM0G3507 + 外接 D24A + 八路灰度 + 42 步进/A4988 预留**。用户明确表示放弃继续调试地猛星的 curve 版本。

当前已知平台：

- 主控：立创·天猛星 MSPM0G3507，当前有效工程声明 `LQFP-64(PM)`。
- 底盘：四轮直流电机小车，D24A 四路 TB6612 驱动板，八路红外灰度循迹板。
- 调试：CCS、XDS110、板载 CH340 串口（115200）。
- 后续球控：K230-CanMV + GC2093 摄像头、Wi-Fi/MJPEG 手机浏览器图传、0.96 英寸屏、MG996R 舵机方案曾安装；当前尝试 42BYGH23-A-21DH + A4988 方案。

## 6. 供电和电平安全结论

### 已实测/用户直接确认

- 电池满电测得约 `12.14 V`。
- D24A `5V-GND`、`3V3-GND` 被用户万用表测为“正常”，未保存精确数值。
- 用户已进行“电脑供电、车轮架空”的电机试验，CH340 有串口数据。
- 灰度模块可按 3.3 V 供电，用户测得白底数字输出 0 V、黑线约 3.3 V。
- 系统必须共地：MCU GND 与 D24A GND 已被作为接线要求反复确认。

### 原理图/数据表或工程文档结论

- 调试拓扑：电脑 USB 给 MCU/CH340 供电；12 V 电池给 D24A `Vin+/-` 与电机功率；MCU 与 D24A **只做信号地共地**。`outputs/H2_LINE_CAR/POWER_AND_D24A_WIRING.md` 记录：USB 给 MCU 时不得把 D24A 5 V/3.3 V 输出并接 MCU 电源，避免倒灌。
- 脱机供电：旧地猛星文档依据其原理图写过“拔掉电脑 USB 后可由 D24A 5 V给开发板+5V”，但当前主控已换天猛星；该结论不能直接迁移，当前天猛星脱机电源入口为 **TBD**。
- MG996R 工作电压用户提供为 4.8–6.6 V。它不能从 MSPM0 3.3 V或 MCU USB 细供电线取功率；需独立足够电流的 5–6 V 降压，且与 MCU 共地。这是原器件参数和电源安全推论，未实接验证。
- 42BYGH23 不能由 MCU GPIO 或普通降压模块直接驱动；当前设计通过 A4988 恒流斩波驱动，逻辑 VDD=3.3 V、VMOT=12 V，VMOT 旁需至少100 uF 电容，所有地共地。A4988接线/限流属于已写设计，未实测。
- 初次执行器测试顺序已写入 `MEMORY_STEPPER_TEST.md`：先 MCU 单独上电、验证 PB15/PA25 安全电平，再单独接 A4988，最后才接 D24A并架空四轮。

### TB6612 5 V逻辑与 3.3 V MSPM0：存在冲突，不能自行定案

- 旧地猛星文档 `POWER_AND_D24A_WIRING.md` 依据其对 D24A 原理图/手册的解读，认为 TB6612 VCC=5 V、保证 VIH=0.7×VCC=3.5 V，因此建议 74HCT/74AHCT 缓冲，且禁止把可调 DC-DC 当成电平转换。
- 当前天猛星文档 `TIANMENG_WIRING_AND_TEST.md` 写为“TB6612FNG 控制高电平门限低于 3.3 V，MSPM0 可直接驱动，无需 HCT”。
- 两者相互矛盾，且没有本线程中“天猛星 3.3 V直连 D24A 在噪声/温度下可靠”的实测记录。后续必须以 D24A 所用 TB6612FNG 原始数据表版本、实际 VCC、以及示波/实测为准；不得把任一文档的结论当作已实板定案。

### 编码器电平风险：尚待确认

- D24A 编码器插座可提供 5 V。若霍尔 A/B 是 5 V推挽输出，不能直接进 MSPM0；若开漏且可上拉到3.3 V才可能安全。旧文档建议先确认输出结构或把编码器 VCC 单独改为3.3 V，但这未实做。
- 用户给出 MG310“编码器 3 或5 V、13 PPR、1:20”，后续照片又为 MG513XP28_12V，因此每轮计数、PPR定义、编码器输出电平都仍是 TBD。

## 8. 当前稳定循迹算法

这里的“当前认可稳定”特指用户要求保留的**地猛星 2026-07-29约22:44 P1 基线**，文件为 `outputs/H2_LINE_CAR/main.c` 和 `car_config.h`。它不是当前天猛星记忆工程的实车验证结论。

### 算法事实

- 传感器定义：`LINE_BLACK_IS_HIGH=1`；`line_read()`将 S1~S8组合为位图，`1=黑线`。用户实测白底应为 `M=0`，中央 S4/S5黑线为 `M=24`。
- 权值：S1～S8分别为 `-350,-250,-150,-50,50,150,250,350`。
- 误差：所有激活传感器权值的算术平均；没有激活传感器则认为丢线。
- PD：`turn = error*0.7 + (error-lastError)*1.8`，再限幅到 `±400`。
- 基础PWM：绝对误差 `<=150` 用220；`150<|E|<=250` 用190；`|E|>250` 用160。PWM单位为千分比，范围0–1000，最终限制为350。
- 差速：`left=base+turn`，`right=base-turn`；方向控制函数决定正负。方向极性只应依据实际架空/落地测试确定。
- 丢线：按最后误差方向执行`55/150`差速搜索，连续400ms丢线后`STATE,FAULT,LINE_LOST`。
- A点：源码实现不是名为`LAP_ARMED`的状态，而是 `g_leftStartLine`：先见到非宽线后置真；运行至少6000ms，之后连续4个5ms控制周期（约20ms）出现 >=6路黑线，即进入`CAR_BRAKE`。
- BRAKE：`motor_short_brake()`将四个方向输入置高、PWM写1000，维持220ms；随后`motor_coast_disable()`，输出`STATE,FINISHED`。
- 计时：`g_runMs`在5ms控制步进中累加；进入刹车锁存`g_finishMs=g_runMs`，完成时加220ms后输出。
- 遥测：每100ms输出 `T,S,M,E,L,R`，含运行时间、状态、位图、上次误差、左右命令。

### 稳定基线参数

| 参数 | 数值 | 来源 | 证据等级 |
|---|---:|---|---|
| 控制周期 | 5ms | `H2_LINE_CAR/car_config.h` | 源码存在，地猛星实车曾用。 |
| 遥测周期 | 100ms | 同上 | 同上。 |
| 最短终点允许时间 | 6000ms | 同上 | 源码存在；停车精度未验证。 |
| 宽线条件 | >=6路，连续4 tick | `H2_LINE_CAR/main.c` | 源码存在。 |
| 短刹时长 | 220ms | `car_config.h` | 源码存在。 |
| 丢线故障 | 400ms | `car_config.h` | 源码存在；对当前赛道内弯是否合适未完整验证。 |
| 直/中/大弯PWM | 220/190/160 | `car_config.h` | 用户称慢但稳定。 |
| 搜索内/外PWM | 55/150 | `car_config.h` | 用户历史基线，不是天猛星实测。 |

`P2_FINAL_LAP_TEST.md` 中提到了 `EVENT,LAP_ARMED`、离开起点250ms、800ms丢线、0/28%搜索、全白启动拒绝和“V3翻转极性”，但该文档自己写明这些 V2/V3 描述“不适用于当前固件”，且与当前 `H2_LINE_CAR/main.c` 不一致。因此它只能作为**历史测试要求/失败方案线索**，不是稳定基线算法事实。
